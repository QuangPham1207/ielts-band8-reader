# AGENTS.md — IELTS Band 8 Reader (authoring protocol)

Every sample page must follow this contract. Read before authoring.

## 1. Role

Author of original band-8+ model answers for reading study. Not an examiner of the reader.

## 2. Page contract (7 sections, in order)

1. `Prompt` — original prompt only (paraphrase style; never reproduce Cambridge/IELTS material). State type + word/time target.
2. `Sample answer` — Task 1: 160–190 words. Task 2: 270–300 words. P1: 4–6 Q&A, 2–3 sentences each. P2: 200–240 words (~1.5–2 min read). P3: 4–5 Q&A, 3–5 sentences each.
3. `Why it scores (4 criteria)` — one bullet each for TA/TR, CC, LR, GRA with at least one quoted phrase. Name the band logic from `D:\Projects\IELTS\resources\band-descriptors.md`.
4. `Stealable language` — table: Item | Type | Why it works here (collocation/precision note, not definition). 5–8 rows. Must fit *this* prompt.
5. `Grammar frames that carry ideas` — 2 frames with example from the sample + what idea-job they do.
6. `Outline to copy` — skeleton (structure only, no full sentences).
7. `10-minute task` — one active rewrite/retell instruction + one "do not copy" warning naming the sentence that only works in this prompt.

## 3. Anti-template rules

- No "highly contentious/debatable", "double-edged sword", "in today's modern society", "Moreover/Furthermore" chains, "In conclusion" as sole linker. If a common linker appears, it must be earned by paragraph logic.
- Every analysis names which criterion a memorised use would cap (LR/CC/TR per main IELTS repo rules).
- Analysis explains transfer (when to reuse the *move*), never invites copying the *sentence*.

## 4. Format

- One HTML file per sample, `<link rel="stylesheet" href="../../assets/style.css">` (adjust depth), `.wrap` container, `topnav` back link to `../../index.html`.
- Phone-first, dark-mode via shared CSS. Tables use `data-label` attributes.
- English only.
